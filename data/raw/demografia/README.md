| [USTAT — Population by age group](ustat_popolazione_per_eta.xlsx) | 2003–2025 | Excel | Population size and age structure. |
| [USTAT — People living in households](ustat_residenti_economie_domestiche.xlsx) | From 2010; see file for coverage | Excel | Number of residents by household size. |
