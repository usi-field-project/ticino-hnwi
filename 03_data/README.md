# Data for analysis

**62 original files:** 13 Excel workbooks, 47 annual CSV files and 2 ZIP archives. The annual files form four time series.

[Home](../README.md) · [Original PDFs](raw/reports/README.md) · [Data guide](DATA_GUIDE.md)

## Where to start

- **Migration in Ticino:** [USTAT Excel workbook](raw/demografia/ustat_movimenti_migratori.xlsx).
- **Migration across cantons:** [BFS 2025 CSV](raw/demografia/bfs_migrazioni_per_cantone/2025.csv).
- **Population by canton and citizenship:** [BFS 2025 CSV](raw/demografia/bfs_popolazione_per_cantone/2025.csv).
- **Healthcare provision:** [BAG 2024 Excel workbook](raw/sanita/bag_ospedali_indicatori_2024.xlsx), together with the [indicator definitions](raw/reports/sanita/bag_ospedali_svizzeri_2024_definizioni_it.pdf).
