# Ticino (baseline)

Status: research template; findings and sources to be collected.

Ticino is the reference territory for the comparison.

**Geographical level:** the baseline is the Canton of Ticino. Lugano is used only as the reference municipality for tax profiles (agreed 19.10.2026); any other Lugano figure is a proxy for the canton. See [Ticino baseline and Lugano](../../02_methodology/benchmark_methodology.md#ticino-baseline-and-lugano).

Use the [shared research topics](../../02_methodology/benchmark_methodology.md#comparison-dimensions). For each finding, record the source, reference year or period, geographical coverage and any comparability limitations. Link to files collected and verified by the team in [the data archive](../../03_data/) instead of copying them.
